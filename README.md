# 📊 Sales Data Analysis Dashboard

An interactive **Sales Data Analysis Dashboard** developed using **Microsoft Power BI** to analyze chocolate sales performance and generate meaningful business insights from sales data.

## 🎯 Project Overview

This project analyzes chocolate sales data to understand overall sales performance, product performance, shipment activity, and other important business metrics.

The dashboard provides an interactive way to explore sales data and identify trends and patterns that can support data-driven decision-making.

## 🚀 How to Use

1. Download the `SALES DATA.pbix` file.
2. Open it using **Microsoft Power BI Desktop**.
3. If required, update the dataset path.
4. Refresh the data.
5. Explore the interactive dashboard using the available filters and visuals.
